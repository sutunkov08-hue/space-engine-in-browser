# Space Engine в браузере

Полноценный трёхмерный космический симулятор, целиком работающий в браузере.
Весь код — в одном самодостаточном файле **`index.html`** (HTML + CSS + JavaScript,
Three.js подключается через CDN). Без сборки, без сервера: просто откройте файл
двойным кликом в Chrome, Firefox или Edge.

## Возможности

- **Космическое окружение**: 9000 процедурных звёзд по спектральным классам
  (голубые, белые, жёлтые, оранжевые, красные), процедурные туманности-шейдеры,
  блум-постэффект, логарифмический буфер глубины — устойчивая картинка от метров
  до световых лет.
- **Солнечная система**: Солнце с бурлящей шейдер-поверхностью, короной и
  протуберанцами; 8 планет на реальных относительных орбитах; процедурные
  поверхности (кратеры, материки, океаны, облака, полярные шапки, ночные
  огни городов у Земли); кольца Сатурна с тенями от планеты; северные сияния;
  9 спутников (Луна, Фобос, Деймос, Ио, Европа, Ганимед, Каллисто, Титан,
  Тритон); пояс из 2400 вращающихся астероидов; 2 кометы с хвостами от Солнца;
  космическая станция (там же заправка) и корабль игрока.
- **Физика**: ньютоновская гравитация, корабль может выйти на орбиту;
  переключаемые орбиты по Кеплеру; вращение планет вокруг оси; управление
  временем от паузы до миллиона раз (кнопка «Сейчас» возвращает реальное время).
- **Корабль**: полные 6 степеней свободы (тангаж, рыскание, крен, перемещение
  по всем осям), режимы «обычный / кинетический (топливо) / свободный»,
  автопилот «подлететь и выйти на орбиту», кнопка «Стоп» гасит инерцию.
- **HUD**: верхняя панель (система, скорость, высота, ближайший объект,
  дата/время симуляции, ускорение времени, FPS); единицы скорости км/с,
  км/ч и в долях скорости света; кликабельная карта системы; панель информации
  об объекте; затухающие маркеры с raycasting-кликом; подсказки (клавиша H);
  меню настроек (качество, туманности, звёзды, орбиты, звук, масштаб планет,
  сила гравитации, мощность двигателя).
- **Дополнительно**: гул двигателя (громкость зависит от тяги) и эмбиент космоса,
  сохранение позиции и настроек в localStorage + кнопка «Сброс», экран загрузки
  с управлением, тач-управление (перетаскивание — осмотр, щипок — зум),
  ограничение delta-time.

## Управление

| Действие | Клавиши |
|---|---|
| Вперёд / назад | `W` / `S` |
| Влево / вправо | `A` / `D` |
| Вверх / вниз | `R` / `F` |
| Тангаж / рыскание | стрелки |
| Крен | `Q` / `E` |
| Ускорение | `Shift` |
| Стоп (погасить инерцию) | `X` |
| Осмотр мышью / выбор объекта (ЛКМ) | мышь |
| Тяга / зум | колесо мыши |
| Замедлить / ускорить время | `T` / `Y` |
| Пауза | `P` |
| Орбиты | `O` |
| Карта системы | `M` |
| Подсказки | `H` |
| Полный экран | `F1` |
| Смена единиц скорости | `1` / `2` / `3` |

## Запуск

1. Скачайте `index.html`.
2. Откройте его двойным кликом в любом современном браузере (нужен интернет
   для загрузки Three.js с CDN).
3. Нажмите «▶ НАЧАТЬ ПОЛЁТ».

Первая настройка — этот репозиторий можно опубликовать через **GitHub Pages**
(Settings → Pages → main branch), тогда симулятор откроется по ссылке сразу
из браузера.

Код разбит на секции с русскими комментариями: рендеринг, шейдеры, физика,
корабль, ввод, HUD, звук, сохранение.
